# 聖誕老人補貨組落地頁 v1（2026-11-25）：參加很多攤交換禮物的社牛必買組

阿寧的需求：「接著做聖誕老人買二送一組，參考大禮包這種風格，做成『參加很多攤交換禮物的社牛必買組』」。

## 組合內容
- 照前台方案卡（new2027-厭世日曆頁，11/25 抓的）：「幹話日曆兩本（顏色任選），送一份手機日曆（款式任選）」，$1,916，46折，原價 $4,140，現省 $2,224。
- 每個日曆頁的補貨組都是「同一款兩本」，所以頁面不寫兩本可以混款。

## 概念：12 月有三攤，一組拆三份剛好
- 第一攤 12/18 公司交換禮物：日曆第 1 本。
- 第二攤 12/21 老同學聖誕趴：日曆第 2 本，同一款也沒關係，「不同圈子不會撞禮」。
- 第三攤 12/24 遠方好友視訊交換：送的手機日曆，轉寄兌換碼，人在國外也收得到。跑完三攤太累的話，也可以留給自己。
- 收尾：「你負責當每一攤最受歡迎的人，禮物交給聖誕老人。聖誕快樂，下一攤見！」

## 視覺
- 沿用大禮包 v4 文青可愛風（`_原始檔/base_allin.py` 就是大禮包的 build_page.py）：米白點點紙、手繪塗鴉、白邊貼紙、紙膠帶、粉彩色塊。
- 新增聖誕紅膠囊、禮物盒和聖誕樹塗鴉，以及禮物吊牌紙條（第一攤／第二攤／第三攤）。
- 示範畫面用幹話曆：封面放天藍和薄荷兩本（同款不同色）加幹話手機日曆。
- 字：中文全部用凝書體，fontTools 檢查沒有缺字。沒有破折號，也沒有「今天的那一句話」。
- 手機只用上半截，切口用「第三攤」紙條蓋住。
